# 皮皮引擎 0.1.0 验收记录

验收环境：Windows、Node 24、已安装的 Microsoft Edge、微信开发者工具原生 WXML/WXSS 编译器。日期：2026-09-11。各项结论基于当前源码、实际构建包和运行检查；不是只检查导出名称。

| 目标 | 对应实现 | 当前证据 |
| --- | --- | --- |
| 可复用的面向对象引擎 | `PipiEngine`、`ActionRegistry`、`AssetManager`、`AnimationPlan` | 43 项 Node 测试通过；实例隔离、扩展计划和插件清理均覆盖 |
| 动作增删改、管理与扩展 | 动作库事务、组合步骤、自定义类型、工作台 JSON 编辑 | 非法帧/时长/方向/循环引用被拒绝；失败不替换旧库；浏览器完成复制、修改、删除、导出、回导 |
| 可控播放 | `Playback`、自然循环、速度、队列、定位和逐帧按钮 | 取消加载、迟到图片、排队、暂停、循环释放、异常回调均验证 |
| 保持现有角色和姿态 | 复用图集、公共脚底锚点、局部覆盖、独立鸟喙 | 浏览器加载真实 PNG，9 个原地动作首尾与默认站姿边界相差不超过 1px；采样帧无空图或边缘截断 |
| 八方向移动 | `MotionPlan` 和实际起终点选向 | 走路和飞行共 16 个方向用例逐一验证；真实 Canvas 检查起止及中间位置，包含起飞和落地 |
| 语音与自然动作衔接 | 持续招手/指向与嘴部轨道 | 招手实时播放记录 60 个逻辑帧；真实 HTMLAudio 使用 WAV 解码和 ended 回调，指向动作完成收翅后 Promise 才结束 |
| 真实成长和单次奖励 | `celebrate()` / `GrowPlan` | 跳跃仅一次，随后说话和成长；取消不触发迟到成长；实际渲染高度从 136px 增至 170px，脚底 y 不变 |
| 资源复用与回收 | 页面去重、解码 LRU、帧隔离、微信文件缓存 | 同一页只解码一次；活动资源受保护；重启复用、ETag 304、MD5 更新、损坏修复、断网、配额不足和清理均通过 |
| Web 直接引入 | ES module 示例、全局脚本工作台 | 桌面与 390px 手机布局通过；单击抚摸、双击取消、导入导出、真实 requestAnimationFrame 和音频通过，无页面脚本错误 |
| 微信小程序接入 | 无 DOM 入口、可直接复制的组件和示例 | 与官方 API 类型核对通过；原生 WXML/WXSS 编译通过；适配器契约覆盖 Canvas、真实 PNG 数据、触摸、页面隐藏恢复及卸载 |
| 其他项目独立安装 | `.tgz` 发布包、四种入口、类型声明 | 系统临时目录新建消费项目并正常 npm 安装；CommonJS 实际创建/播放/释放、ES module、浏览器打包器及无 DOM 微信入口均通过 |
| 易于运行和维护 | `npm run dev`、格式化源码、API/接入文档、素材导出工具 | 本地服务验证 `.mjs` MIME；33 张图集逐个 MD5/大小校验后可导出；无识字/数学工作区源码依赖 |

## 复现命令

```sh
npm ci
npm test
npm run test:types
npm run build
npm run test:browser
npm run test:wechat
npm run test:package
npm run export:assets -- test-results/engine/exported-assets
```

`test-results/engine/` 下生成浏览器报告、桌面/手机截图、项目往返 JSON、微信编译产物与包验证记录；运行结果文件不纳入 Git。源码测试及检查工具全部纳入版本管理。发布包约 0.85 MiB，解包后约 1.55 MiB，其中微信使用的单个构建入口约 0.38 MiB。整套 PNG 约 40.2 MiB，独立托管，未塞入小程序主包。

这次还修复了真实检查中发现的相邻图格缩放串色、导入路径重复拼接、鼠标自动释放捕获导致单击失效，以及局部动作期间身体点击区域偏移。没有重新生成或改变原 PNG 像素。

## 验证边界

微信原生编译和适配器契约不是 iOS/Android 真机视觉、音频权限测试。当前交付是独立引擎、组件、工作台及可安装包；没有改动识字/数学生产项目，也没有发布到 npm 公共注册表。默认远程素材及欢迎音频地址已确认返回 HTTP 200，CORS 可用；离线首次访问尚未缓存的动作仍需要网络，随包的基础姿态与招手不需要。
