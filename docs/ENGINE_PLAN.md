# 皮皮动画引擎：目标与验收

用户目标：为皮皮建立可扩展、可修改、可管理、易于被其他项目直接引入的面向对象动画引擎，支持 Web 和微信小程序。

## 实现结构

- `PipiEngine`：统一控制播放、暂停、定位、速度、移动、独立嘴部轨道、语音同步、真实成长、自由活动和资源释放。
- `ActionRegistry`：数据化动作定义，注册、修改、删除、查询、导入导出；原子校验，避免无效修改破坏当前动作库。
- `AssetManager` / `CanvasRenderer`：图集与帧数据管理、锚点与统一尺寸、透明局部轨道、预加载、内存回收。
- 动作计划与扩展接口：剪辑、组合步骤、循环和自定义计划；调用方可新增动作或插件，不需要修改平台代码。
- `WebAdapter` / `WechatAdapter`：分别处理 Canvas、图片、网络、时钟、音频与缓存；核心不依赖 DOM 或微信全局对象。
- 内置皮皮动作包：复用已确认的透明 PNG、帧顺序与时间，覆盖表情、单翅指字、自然招手、八方向走路和飞行。
- 引擎工作台：基于公开 API 管理动作、调整节奏、预览定位、导入导出，提供直接可运行的接入代码。
- 发布包：浏览器脚本、ES module、CommonJS、微信小程序入口与类型声明；示例不依赖识字/数学项目的内部模块。

## 完整验收清单

- [x] 面向对象公开 API 和文档一致；多个实例状态相互独立。
- [x] 注册、修改、删除、导入导出和自定义动作类型可实际使用，并校验非法引用/时间/帧边界。
- [x] 动作播放、暂停恢复、速度、逐帧定位、自然结束、取消、排队和重复命令的语义明确且经过测试。
- [x] 使用现有皮皮素材，统一身体尺寸和地面锚点；动作首尾不跳位。
- [x] 走路与飞行根据真实位移选择八方向，完整经历起止阶段，其他动作保持位置。
- [x] 独立嘴部轨道与自然招手/单翅保持可组合；语音结束后正确收尾，取消与后台生命周期不会误播。
- [x] 成长保留最终尺寸；组合反馈支持跳跃一次、播报后成长。
- [x] 资源可配置、预加载、复用和释放；微信持久缓存/内容校验/离线回退与异步销毁安全经过验证。
- [x] Web 示例和管理台在真实浏览器中运行，管理操作有完整数据往返验证。
- [x] 微信入口在无 DOM 环境可加载；原生组件/示例可编译，实际适配器契约覆盖 Canvas、文件缓存、触摸、隐藏/恢复和销毁。
- [x] 从独立消费项目安装发布包即可使用，无开发工作区绝对路径依赖；包体内容和大小已检查。
- [x] 可复现的检查命令、集成示例、迁移说明、能力限制和验证记录齐全。

这是一份持续执行的完整目标清单。只有逐项有当前文件与运行证据支持后才视为完成；浏览器代理测试不能代替微信真机结果。
