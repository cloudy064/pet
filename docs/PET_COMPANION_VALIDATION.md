# 学习宠物扩展：实现与验证记录

当前状态：宠物模块、16 个透明新动作、网页体验与原创示例音频已落地并通过下列本地验证。微信原生新增体验及 iOS/Android 真机验收尚未完成；不能把本记录当作生产项目的整体验收。

## 已实现

- 可选 `PetCompanion` 模块及 CommonJS、ES module、浏览器全局、微信入口与类型声明。
- 有上限的对数成长曲线、先保存再反馈、事件/收据去重、存档恢复、离线变化上限；永久成长不会因喂食或离线倒退。
- 首页/学习/照料/休息/后台模式，带权且避免连续重复的待机、主动请求与题目边界休息提醒。
- 可配置点击/双击回应、兼容旧交互、连续抚摸识别、照料时放大；初始化失败清理与在途保存期间切页保护。
- 喂食持久化、幂等钱包契约、余额不足、响应丢失与重试恢复；身体网格洗澡、覆盖率、冲洗和中断恢复。
- 16 个新动作共 538 帧，19 张透明分页 PNG；深浅背景接触表、完整计时清单、独立葵花籽/木桩、分段自然释放及实际播放阶段事件。
- 原始生成图保持完整。母版、帧映射、制作脚本、哈希、文件校验与素材导出命令已提供，PNG 采用已有 Git LFS 规则。
- 中英台词、业务录音 URL、可选浏览器语音与取消清理；两首原创数数歌合成歌声示例、走路往返组合。
- 小院网页、学习/照料模拟、逐帧预览、道具开关、独立香皂/泡泡/水流层。

浏览器报告和截图位于忽略目录 `test-results/companion/`，最新完整报告中 `newImages:true`。长期保留的文件实检结果为 `assets/companion/validation.json`，浏览器结果为 `assets/companion/browser-validation.json`。接触表和光流过渡已在深浅背景抽查；自动检查不替代逐台设备的视觉体验。

PNG 下载总计 26,252,024 字节，单个动作最大 RGBA 解码 6,861,888 字节，页边长不超过 1610。浏览器依次播放全部动作时，资源管理器记录的已解码图集峰值为 47,552,672 字节，低于其默认 48 MiB 预算。这是图集缓存计数，不含 GPU、副本、音频或浏览器进程总内存，也不是微信真机内存测量。

本机无界面 Chromium 以 160px 身体高度持续扑翅，120 个帧回调间隔共 1984ms，平均 60fps，CPU 绘制耗时 P95 约 0.7ms；测量不含 GPU 呈现，也不代表手机帧率。

浏览器依赖可用 `python -m pip install -r requirements-browser.txt` 安装，再执行 `python -m playwright install chromium`。素材重建使用 `requirements-companion-assets.txt`；音频重建还需 `requirements-companion-audio.txt`、eSpeak NG 和 ffmpeg。日常使用与播放不需要这些制作依赖。

## 仍需在引用项目验收

1. 微信模块和适配器契约已验证；新增体验尚未通过微信原生编译、触摸/音频实际帧率以及 iOS/Android 真机峰值内存检查。
2. 原创歌曲是合成歌声示例，不是专业真人录音；已验证媒体解码与生命周期，演唱自然度、发音和目标年龄适配仍需试听确认。可用业务提供的曲目替换。
3. 示例钱包只演示本机流程；真实项目仍需账号账本、单调收据序号、跨设备幂等和云存档。任务产出、消费节奏与每日有效奖励上限由引用项目配置。
4. 数值沿用方案的默认选择：永久学习成长不倒退，不强制花空余额。目标设备、年龄、体况缩小是否另行启用，以及最终录音来源仍属于产品配置与验收决策。

## 本轮边界修复（2026-09-12）

- 照料流程拆为 `engine/companion/care.js`。存下的洗澡进度不再覆盖抚摸；抚摸时洗澡输入无效；洗澡后台恢复和冲洗结束期间切后台均有回归。
- 学习事件 revision 改为必填；近期 ID 淘汰后仍能依靠水位拒绝旧事件。示例钱包拆为 `examples/companion/ledger.js`，事件编号先持久化，按序恢复投递。
- 内置存储增加期望版本原子比较。Web 使用跨标签页锁；微信按 wx 对象/key 串行写入。并发冲突明确报错，同 ID 重试可恢复；不会重复扣款或覆盖另一协调器的奖励。
- 小院示例只允许一个标签页持有本地账号锁，退出后关闭旧钱包写入并释放资源；刷新后接续同一存档。
- 调用兼容性变化、云端存储契约和旧代码定位已在 API 文档及 README 说明。原存档 version:1 保持可读；未增加账号服务或宣称跨设备已验收。
