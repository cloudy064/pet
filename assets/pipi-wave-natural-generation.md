# 自然打招呼：生成来源与提示词

当前播放器已更新为 v8：`pipi-wave-smooth.png`。`prepare_wave_smooth.py` 从以下生成成果中筛选连续关键姿态，对独立翅膀图层进行双向光流配准并制作过渡，以距离场重建单一轮廓；表情另用完整画面。收翅复用抬翅路径。这次修复没有重新调用图像生成工具，下面保留原始提示词与 v7 处理记录作为来源。前后对比见项目根目录 `皮皮_打招呼对比.html`。

本次使用内置 image_gen 工具生成整个人物的连续姿态。工具没有暴露模型版本选择，未指定或宣称使用名为 image2.5 的模型。当前静态 PNG 是角色身份和首尾姿势参考；用户第二张图片是展开翅膀、笑脸、眨眼的中间态参考。

pipi-wave-natural-storyboard.png 为动作草稿。它未严格满足请求的帧数，不能作为帧数依据。随后分四次生成 A、B、C、D 四张 4×4 姿态图，对应准备抬翅、展开与眨眼、轻挥与微笑、收翅。源 PNG 保存在当前目录。

原始动作素材由 prepare_wave_generated.py 进行透明背景处理、边缘清理、整体等比缩放、脚底对齐和横向拼接；没有用旋转或拉伸某一张翅膀贴片制造中间姿态，也没有图像混合补帧。按完整角色的实际轮廓提取，避免生成图的非整齐排版切掉头顶或混入邻格羽毛。

第二段前三张与第一段尾部重叠，已移除；收回段中少量回退姿态已调序。最终 61 帧、30 fps、约 2.03 秒，PNG 为 29280×512，每格 480×512。首尾使用当前静态图，中间 59 张为生成画面。原始处理结果的 PNG、JSON、抽帧预览以 pipi-wave-generated 命名，保留作为来源。

上一版播放器使用后续稳定处理后的 pipi-wave-stabilized.png。stabilize_wave_generated.py 对生成帧进行头部配准，再提取生成的展翅画面，合成到固定的静态头部、身体、右翅和双脚底图上；表情单独对齐，保持眨眼和微笑时使用固定表情画面。这一步没有重新调用图像生成工具，也没有通过旋转单张翅膀制造动作。首尾保持原静态姿势，头顶、右眼、躯干、右翅和左右脚的检查区域在全部 61 帧中逐像素一致。验证记录见 pipi-wave-stabilized-validation.json；羽毛本身仍采用生成姿态，固定区域检查不等于所有羽毛变化都已完全平滑。
