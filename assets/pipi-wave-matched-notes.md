# 与静态姿态衔接的打招呼

当前素材为 `pipi-wave-matched.png` 与同名 JSON，96 格横排、每格 336×422、60 fps、1.6 秒。

上一版虽然首尾彼此一致，但底图来自另一套生成的打招呼姿态，因此与默认静态图的嘴形、体型、翅膀轮廓不一致。本版使用当前调试台的静态原图 `pipi-idle.png` 作为直接来源。

- 首尾均为静态 PNG 等比缩为 211×422 后放入 x=107、y=0 的透明画布；制作时逐像素核对。
- 运动部分从静态图本身提取左翅。沿连续角度和展开比例变换，保留原有羽毛纹理。
- 脸、右翅和脚保持原图。仅在原来被左翅遮住的位置，使用已有抬翅姿态里的绿色躯干位图补齐，并匹配接缝颜色。
- 不再使用上一版单独生成的大扇形翅膀，因此展开后的羽毛轮廓也随原图调整。
- 当前调用方式是已经授权的本地图片提取、变换和拼接，没有新调用 image_gen，也没有通过代码绘制角色。

运行 `python prepare_wave_matched.py`，随后运行 `python build_asset_registry.py`。PNG 与 JSON 的输出路径均在本目录。浏览器使用共同显示比例，并提供真正的“静态原图对照”，不会把当前动作自己的首帧充作原图。
