# 挥翅打招呼生成记录

使用内置 image_gen，随后用 prepare_wave.py 本地抠图并对齐脚底。输出 pipi-wave-strip.png，RGBA 4096×724，8 格。保留生成原稿 pipi-wave-draft.png。只处理背景和画面定位，没有程序绘制翅膀。

## 最终提示词

Create a horizontal sprite strip for a friendly single-wing waving animation. Input image 1 is the character identity and neutral front-facing pose: preserve this exact Pipi green baby parrot with cream face, turquoise eyes, yellow orange beak, orange feet, blue/yellow/green feathers and soft dimensional 3D illustrated material. Input image 2 is a gesture reference only, not a different character to copy. Output ONE horizontal row of exactly EIGHT evenly spaced equal-width cells, wide PNG around 3072x1024, each cell centered on its own character with identical body height and feet baseline. Every cell full body, crest and feathers entirely within its cell, generous side spacing for the extended wing. Only the wing on VIEWER LEFT moves. Frames: 1 both wings folded neutral; 2 viewer-left wing partly lifted sideways; 3 viewer-left wing fully raised with spread blue and yellow feathers waving hello; 4 same wing slightly lowered and tilted outwards; 5 wing fully raised again; 6 same wing slightly lowered and tilted outwards again; 7 wing lowering halfway back toward body; 8 both wings folded exactly identical to frame 1. Head, beak expression, open eyes, body, feet, opposite wing, camera, character scale and lighting remain identical through all frames. No wink, no head turn, no jumping. No text, labels, symbols, dividers, numbers or speech marks. Actual transparent alpha PNG background. If alpha output is unavailable use perfectly uniform light gray #CCCCCC behind characters (never checkerboard or textured background) for clean subsequent extraction. No ground, no shadows outside character. Production sprite sheet, one row eight cells, not a grid.
